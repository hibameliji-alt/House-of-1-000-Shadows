# The Mystery Files 3D

A third-person 3D mystery game with 1,000 cases. Style your investigator, then in every case you arrive at a new house: a different paint color, a different setting (countryside, snow, beach, desert, forest, moonlit estate), and a different layout with several floors, a hallway with stairs, and rooms like a kitchen, bathroom, bedroom and library.

Find the body, search with your tools, and question every guest. One guest lied about where they were.

- Tools: magnifier (fiber at the body), UV light (hair at the body), hand test (residue on a guest's hands)
- Floors: step on the purple pad to go up, the green pad to go down
- Controls: on-screen stick or WASD/arrows to walk, drag to look around, buttons or E/Space to act, 1/2/3 to pick a tool

One `index.html`, no build step. Three.js loads from cdnjs, so you need an internet connection.

Deploy: add `index.html` to a GitHub repo, then Settings > Pages > Deploy from a branch (`main`, `/ (root)`).
